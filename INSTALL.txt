GAMETOPIA M6.206 - FRONTEND (NO NESTED FOLDER)
================================================

FRONTEND: M6.206
BACKEND REQUIRED: M6.198 (unchanged)
LIVE PLAYTEST: https://gametopia-playtest.onrender.com/

IMPORTANT: This ZIP opens DIRECTLY to index.html, games.html, src, assets, etc.
It DOES NOT contain an inner GameTopia-Frontend-main folder.

INSTALL USING WINDOWS EXPLORER AND GITHUB DESKTOP
1. Extract this ZIP to a temporary folder outside your repository (for example Downloads\GameTopia_M6_206).
2. In GitHub Desktop, select GameTopia-Frontend; use Repository > Show in Explorer.
   The destination should be C:\Projects\Gametopia\GameTopia-Frontend
3. In the temporary extracted folder, Ctrl+A to select ALL top-level files
   and folders (index.html, src, assets, README.txt, etc.). Ctrl+C.
4. In the destination repository folder, Ctrl+V and choose Replace files.
   Do NOT copy a whole outer extracted folder into the repository.
   Do NOT touch or delete the .git directory.
5. Confirm in the destination itself that src\version.js says M6.206.
6. In GitHub Desktop review the changes. If it reports remote commits, Fetch/Pull and
   reconcile them before pushing; never use Force Push. Commit as GameTopia M6.206.
7. Push origin to TerraNovaDevelopment/GameTopia-Frontend.
8. After Render's GameTopia-Playtest deployment says Live, open
   https://gametopia-playtest.onrender.com/release-check.html
   and confirm M6.206. Then Ctrl+Shift+R on the playtest homepage.

CLEANUP (OPTIONAL, AFTER CONFIRMING THE LIVE SITE WORKS)
An old C:\Projects\Gametopia\GameTopia-Frontend\GameTopia-Frontend-main
folder may remain from earlier extracts. That folder is NOT the repository root.
Do not delete it until you confirm the root files and the live website are correct.

This packaging release does not modify gameplay, login behavior, autosaves, or
backend services. It has not been live tested.

M6.206 notes: see README_M6_206.md and NON_AI_ISSUES.md for verified changes and remaining tests.
