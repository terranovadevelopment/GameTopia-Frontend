GAMETOPIA — HOW TO PLAY BUTTON UPDATE
===================================
Target: Current GameTopia-Frontend source, including M6.198.
This is a targeted patch, NOT a full replacement frontend release.

1. Download or open the current GameTopia-Frontend project folder.
2. Extract all files in this patch ZIP into that frontend folder.
3. Open Windows Command Prompt in the frontend folder.
4. Run: py apply_update.py
   (or: python apply_update.py)
5. Confirm index.html and armageddon.html were updated.
6. Commit and push README.txt, how-to-play.js, index.html, armageddon.html.
7. Render/GitHub Pages will deploy according to your existing setup.

Result: How to Play button on opening splash and main battle page.
Both load the same README.txt in a scrollable popup. Close or Escape to dismiss.
The patch does not touch backend or change backend compatibility version.
Backups: index.html.before-how-to-play and armageddon.html.before-how-to-play.

Alternative manual integration:
Copy README.txt and how-to-play.js into frontend root; insert
<script src="how-to-play.js?v=howto1" defer></script>
immediately before </body> in BOTH index.html and armageddon.html.
