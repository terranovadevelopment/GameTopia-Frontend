# GameTopia / ARMAGEDDON M6.196

- Senior players can open a top-bar KICK dialog and remove an enrolled player on their own side, including themselves, during Planning.
- On removal the next senior player on that side inherits the removed player’s divisions, cities, and orders.
- When a side has no enrolled humans remaining, existing units on that side become AI controlled. If no human remains anywhere, the game is marked completed/archived, with no AI-vs-AI execution.
- Remaining players reset Not Ready and each receives the required acknowledgment notice.
- COMM remains in the top bar and opens the existing common/team/private recorded voice and microphone test UI.
- No change to beginning-of-turn autosaves, PostgreSQL, or disconnected player membership.
