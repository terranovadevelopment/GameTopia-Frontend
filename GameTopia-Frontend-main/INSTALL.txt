GAMETOPIA M6.203 - COMPLETE FRONTEND
=================================

This ZIP contains the complete frontend, starting from your uploaded M6.202 ZIP.
Do NOT mix files from different releases. Backend remains M6.198.

HOW TO DEPLOY
1. Extract this ZIP on your computer.
2. Open the INNER folder named GameTopia-Frontend-main.
3. Copy all its CONTENTS into your local GameTopia-Frontend repository folder, replacing the matching files.
4. In GitHub Desktop, check Changes and commit as GameTopia M6.203.
5. If GitHub Desktop reports newer commits on the remote, use Fetch/Pull first; do not force push or discard changes. Resolve any conflicts before committing.
6. Push origin. Allow Render to finish deployment.
7. Open https://gametopia-frontend.onrender.com/release-check.html
   The page must show GameTopia Frontend M6.203 and the M6-203 build marker.
8. Refresh your GameTopia screen with Ctrl+Shift+R and confirm the top-left label M6.203.

LOGIN TEST
Select ARMAGEDDON. A player not yet authenticated must log in BEFORE seeing the first backstory page. A returning valid session can be verified and proceed without entering a password again.

NOTE: This release preserves the supplied login flow; it has not been live-tested against backend authentication. It does not restore autosaves or fix AI production.
